# Policy channels and typed controls

`compilePolicyConfiguration` now combines the action/evidence compiler with channel and limit validation. It returns `configuration-only` data; it does not publish a policy, enable an account, enforce a transaction limit at a bank, or activate a request.

Enabled online, mobile and API channels require a separate representative identity and an institution acknowledgment requirement. Digital transaction channels also require MFA. Institution overrides can disable an available channel or strengthen MFA, but cannot remove a catalog security minimum, enable a restricted channel, change its access level, or replace its action scope. Unknown channels and action references are rejected.

Supported control kinds are maximum amount in integer minor units, maximum duration in whole days, minimum approver count, and maximum count within a fixed whole-hour window. Values must be positive safe integers; dual approval starts at two people. Amount controls require a three-letter currency code, and only frequency controls accept a time window. Institution overrides can tighten an unlocked limit, never weaken it; locked values cannot change. Currency, window, kind and action scope remain fixed. Original definition sources and changed-value sources are preserved separately.

Eleven focused tests cover security prerequisites, permitted strengthening, restricted channels, tighter/weaker/locked limits, numeric bounds, unit/approval checks, unknown references, duplicates, stable ordering and detached history. All 207 domain tests, TypeScript, lint and optimized build pass. The updated local PostgreSQL verifier now compiles all four sections, captures the snapshot, saves its exact bytes and verifies the independent database hash and permissions. Fixtures roll back. Its final script lint check also passes.

This validates structure and declared limits, not complete semantics. Currency support, product/category/retention catalogs, action/channel compatibility, conditional evidence, providers, disclosures, exceptions and jurisdiction applicability still require governed resolution. Custom action text cannot establish legal permission. Publication must resolve trusted source versions on the server and enforce authentication/AAL2, version, idempotency, concurrency and audit requirements. The compiler output is not a substitute for those commands or external entitlement acknowledgment.
